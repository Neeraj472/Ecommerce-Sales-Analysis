# E-commerce Sales Analysis Dashboard 📊

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data to understand sales performance, profitability, product trends, and regional performance. The dataset was cleaned and prepared for analysis, and an interactive dashboard was developed using Microsoft Power BI to present business insights through visualizations.

## 🎯 Project Objectives

- Clean and prepare raw e-commerce data for analysis.
- Analyze sales, profit, order volume, and product performance.
- Identify top-performing product categories and regions.
- Understand monthly sales trends.
- Build an interactive Power BI dashboard to support data-driven business decisions.

## 🛠️ Tools & Technologies

- **Microsoft Excel:** Dataset inspection and data preparation.
- **Microsoft Power BI:** Dashboard development and data visualization.
- **DAX:** Measures and business calculations.
- **Power Query:** Data transformation and cleaning, if used in the project.

## 📈 Dashboard Features

- **Sales Overview:** Summary of overall sales performance.
- **Monthly Sales Trend:** Tracks changes in sales over time.
- **Product Analysis:** Compares sales across products and categories.
- **Profitability Analysis:** Examines profit performance where profit data is available.
- **Regional Analysis:** Compares sales across available geographical regions.
- **Interactive Filtering:** Allows users to explore the data using available slicers and filters.

## 🔍 Key Results & Insights

The dashboard is designed to identify important business trends, including:

- Total sales and order volume.
- Monthly sales patterns and changes.
- Best-performing product categories.
- Regional sales performance.
- Profitability and order-status patterns, where supported by the dataset.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `dashboard/ecommerce-powerbi.pbix`.
4. If prompted, update the data source path to the included dataset.
5. Refresh the data if required.
6. Explore the dashboard using its charts, filters, and slicers.
